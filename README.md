# 🌿 Highlightse Word

Облачный текстовый процессор (аналог Microsoft Word) в изумрудной эстетике с WebGL 3D-фоном (Three.js).
Полностью совместим с **GitHub Pages** и локальным запуском через **Python (Flask)**.

## ✨ Возможности:
- **Абсолютно чистый лист А4**: без предзаполненных примеров текста, паролей и выдуманных имён.
- **3 вкладки авторизации**:
  - 👨‍🎓 **Вход для ученика** (по логину).
  - 🌱 **Регистрация ученика** (Имя, Фамилия, Дата рождения, Логин).
  - 👨‍🏫 **Преподаватель** (рабочие логины `teacher1` – `teacher10`).
- **Инструменты Word**:
  - 6 шрифтов: **Helvetica, Futura, Roboto, Montserrat, Garamond, Times New Roman**.
  - Размер шрифта от **5 до 72 px** + настройка межстрочного интервала.
  - Начертание: Жирный, Курсив, Подчёркнутый, Перечёркнутый, Индексы, Выравнивание и Списки.
  - 🖍️ **Плавный выделитель** со скруглёнными краями (4 цвета) и палитра цвета текста.
  - ✅ **Интерактивные SVG чек-боксы** с анимацией и кнопкой удаления (`✕`).
  - 💾 **Автосохранение**, экспорт в `.DOC` (MS Word) и печать в PDF.
  - 🌙 **Тёмная и светлая темы** + интерактивная 3D-сцена.
